# 小說閱讀器

一個純靜態、零依賴的網頁小說閱讀器。只要把 `.txt` 小說放進 `content/` 資料夾，在 `booklist.csv` 裡登記書名，就可以在瀏覽器直接閱讀。

項目針對手機瀏覽器做了兼容處理，特別是在華為瀏覽器 / Android WebView（Chrome 78 內核）等較舊環境中也能穩定運行。

---

## 功能特點

- **書單管理**：從 `content/booklist.csv` 讀取書單，每行一個書名，自動略過表頭。
- **正文載入**：按 `content/書名.txt` 路徑讀取小說內容，支援 UTF-8 中文文本。
- **閱讀設定**
  - 字體大小：8 – 128 px，可用滑桿、加減按鈕或直接輸入數字。
  - 行距：1.3 – 2.8，即時預覽。
  - 字體：明體（襯線）／黑體（無襯線）切換。
  - 配色：內置「白紙／淺灰／豆沙綠／夜間」四套預設。
  - 自訂：背景色與文字色支援 6 位或 3 位十六進制色碼，也可用系統取色器。
- **全文搜尋**：搜尋當前書籍內容，標記全部匹配項，支援上一個／下一個跳轉，最多標記 5000 處。
- **閱讀進度**
  - 頂欄即時顯示閱讀百分比。
  - 捲動位置按書籍分別記住，下次打開自動回到原位。
  - 閱讀偏好（字號、行距、字體、配色）自動儲存。
- **沉浸式互動**
  - 向下捲動自動收起頂欄，向上捲動或停低後恢復。
  - 捲動超過 600 px 顯示「回到頂部」浮動按鈕。
  - 書目彈窗可隨時切換書籍，正在閱讀的書會標註「閱讀中」。
- **手機適配**
  - 打開「Aa 設定」時**不會**自動彈出軟鍵盤（只有在偵測到桌面指針環境時才會自動聚焦書名輸入框）。
  - 響應式佈局，適配手機、平板與桌面。
  - 支援 `viewport-fit=cover` 與安全區域（`env(safe-area-inset-*)`）。
  - 不使用 `<select>`，所有選擇均為自訂按鈕組，避免舊版 WebView 的原生控件問題。
- **舊內核兼容**
  - 不依賴 `color-mix()`、`clamp()` 等新特性；輔助色由 JavaScript 動態計算。
  - 使用 `-webkit-` 前綴與 `@supports` 做漸進增強。

## 項目結構

```
/項目/
├── content/
│   ├── booklist.csv        # 書單，每行一個書名（不含 .txt）
│   ├── 西遊記.txt           # 書籍正文，UTF-8 編碼
│   ├── 紅樓夢.txt
│   └── ...
└── index.html              # 閱讀器本體（單一檔案，含全部樣式與腳本）
```

## 快速開始

1. 下載或複製本項目，保持上述目錄結構。
2. 把小說 `.txt` 檔案放入 `content/` 資料夾，檔名即書名（例如 `西遊記.txt`）。
3. 編輯 `content/booklist.csv`，每行寫一個書名（**不要**帶 `.txt`）：

   ```csv
   西遊記
   紅樓夢
   三國演義
   ```

   也可以帶表頭，程式會自動識別並略過：

   ```csv
   書名
   西遊記
   紅樓夢
   ```

4. 用瀏覽器打開 `index.html`。

> **注意**：由於使用 `fetch` 讀取 `content/` 下的檔案，請透過 **HTTP(S) 伺服器**存取，不要直接雙擊用 `file://` 打開（瀏覽器會因本地檔案安全策略而載入失敗）。

### 本地調試

任選一種方式啟動一個靜態伺服器：

```bash
# Python 3
python -m http.server 8000

# Node.js（需先安裝 npx）
npx serve .
```

然後存取 `http://localhost:8000/`。

部署到 GitHub Pages、Netlify、Vercel 或任意靜態空間時，直接上傳整個目錄即可。

## 使用說明

| 操作 | 位置 | 說明 |
| --- | --- | --- |
| 切換書籍 | 底部「書目」按鈕／書單頁 | 彈窗中選擇，當前書標註「閱讀中」 |
| 輸入書名閱讀 | 底部「Aa 設定」→ 書名 | 輸入書名後按「閱讀」或按 Enter |
| 搜尋內容 | 頂欄「搜尋」 | 輸入關鍵詞，↑／↓ 跳轉，✕ 關閉 |
| 調整閱讀樣式 | 底部「Aa 設定」 | 字號、行距、字體、配色 |
| 回到頂部 | 右下角「↑」 | 捲動超過 600 px 後出現 |
| 關閉彈窗 | 點擊遮罩／✕／Esc | 鍵盤 Esc 可依次關閉書目、設定、搜尋 |

**快捷鍵**

- `Enter`：在搜尋框中查找下一個；`Shift + Enter` 查找上一個。
- `Esc`：關閉當前打開的浮層。

## 自訂與配置

所有預設值都集中在 `index.html` 的腳本開頭：

```js
const DEF = { fs: 20, lh: 1.9, ff: 'serif', bg: '#FFFFFF', fg: '#1B1D21' };
```

| 欄位 | 含義 | 取值範圍 |
| --- | --- | --- |
| `fs` | 預設字號（px） | 8 – 128 |
| `lh` | 預設行距 | 1.3 – 2.8 |
| `ff` | 預設字體 | `'serif'` / `'sans'` |
| `bg` | 預設背景色 | 十六進制色碼 |
| `fg` | 預設文字色 | 十六進制色碼 |

修改配色預設（`PRESETS` 陣列）：

```js
const PRESETS = [
  { n: '白紙',   bg: '#FFFFFF', fg: '#1B1D21' },
  { n: '淺灰',   bg: '#E8EAED', fg: '#22252A' },
  { n: '豆沙綠', bg: '#CCE5D0', fg: '#1F2D22' },
  { n: '夜間',   bg: '#14171B', fg: '#C8CDD5' }
];
```

修改字體棧（`FONTS` 物件）可替換為系統已安裝的其他字體。

## 本地儲存說明

閱讀偏好與進度儲存在瀏覽器 `localStorage` 中，鍵名如下：

| 鍵名 | 內容 |
| --- | --- |
| `ytr:set` | 閱讀偏好（字號、行距、字體、配色） |
| `ytr:pos:書名` | 該書的捲動位置（0 – 1 的比例值） |

清除瀏覽器資料或更換裝置後，這些設定會重設。進度按**比例**儲存，因此不同螢幕尺寸下也能大致定位到相同位置。

## 瀏覽器兼容性

- **目標環境**：華為瀏覽器 / Android WebView（Chrome 78 內核）、手機版 Safari、Chrome、Edge、Firefox。
- 已在程式碼層面避開 `color-mix()`、`clamp()`、`<select>` 等在该環境下可能失效或體驗不佳的特性。
- 使用 `@supports (bottom: env(safe-area-inset-bottom))` 為瀏海屏／手勢條裝置做安全區域適配；不支援時自動略過。
- 若需支援更舊的瀏覽器，可自行補充 `fetch` polyfill 或改用 `XMLHttpRequest`。

## 常見問題

**Q：打開後提示「找不到書單檔案」？**
A：確認 `content/booklist.csv` 存在，且透過 HTTP(S) 存取而非 `file://`。

**Q：點擊書名提示「找不到這本書」？**
A：檢查 `content/` 下是否有對應的 `.txt` 檔案，檔名（含大小寫、空格）必須與書單中的名稱完全一致。

**Q：中文顯示亂碼？**
A：請將 `.txt` 和 `.csv` 檔案儲存為 **UTF-8** 編碼。

**Q：搜尋沒有結果或標記異常？**
A：搜尋僅在**已載入的當前書籍**內進行；單次最多標記 5000 處。

**Q：在手機上點「Aa 設定」書名輸入框沒有自動聚焦？**
A：這是刻意設計——避免自動彈出軟鍵盤遮擋設定面板，需要輸入時手動點擊即可。

**Q：書單裡可以寫子目錄嗎？**
A：出於安全考慮，書名中不允許包含 `/`、`\` 或 `..`，所有書籍均直接放在 `content/` 下。
